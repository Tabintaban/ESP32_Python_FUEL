# Система безопасного выполнения программ для ESP32

## Обзор

Этот проект реализует безопасную систему для ESP32 с использованием MicroPython, которая позволяет динамически загружать, расшифровывать и выполнять программы из зашифрованных JSON-файлов. Система обеспечивает высокую производительность, безопасность и изолированное выполнение кода.

## Архитектура

Система состоит из следующих компонентов:

1. **CryptoManager** - Обрабатывает шифрование/дешифрование с использованием AES-GCM
2. **ObjectFactory** - Создает динамические объекты с внедрением методов из JSON
3. **ExecutionSandbox** - Выполняет код в защищенной, ограниченной среде
4. **ProgramLoader** - Загружает и проверяет программы из зашифрованных JSON-файлов
5. **FastJSONLoader** - Оптимизированный парсер JSON для быстрой загрузки
6. **LineBasedCompiler** - Эффективно компилирует строко-ориентированный код
7. **ExecutionEngine** - Выполняет программы с кэшированием и горячей заменой
8. **LightweightSecurity** - Проверяет цифровые подписи и управляет разрешениями
9. **MemoryOptimizer** - Управляет памятью и оптимизирует использование ресурсов

## Особенности

### Безопасность
- Шифрование AES-GCM для JSON-файлов
- Проверка подписи в стиле Ed25519
- Изолированное выполнение в песочнице
- Ограниченный доступ к API для предотвращения опасных операций
- Возможность ротации ключей

### Производительность
- Время от загрузки до выполнения < 500 мс
- Потребление RAM < 50 КБ на программу
- Поддержка горячей перезагрузки без перезапуска
- Кэширование скомпилированного кода

### Оптимизации для ESP32
- Использование bytearray вместо str где возможно
- Предварительно выделенные буферы
- Мониторинг памяти и очистка
- Пакетная обработка данных

## Требования

- Микроконтроллер ESP32
- Прошивка MicroPython с:
  - Файловая система (LittleFS/SPIFFS)
  - Криптографические операции (AES/ChaCha20)
  - Разбор JSON

## Установка

 1. Залейте ваш ESP32 прошивкой MicroPython
 2. Скопируйте все файлы `.py` в файловую систему ESP32
 3. Создайте каталог `programs/` для зашифрованных программных файлов
 4. Создайте каталог `data/` для расшифрованных файлов HTML, CSS и JS

## Использование

Система теперь работает с двумя типами папок:
- `programs/` - для зашифрованных программных файлов
- `data/` - для расшифрованных файлов HTML, CSS и JS

### Базовое использование
```python
from fast_json_loader import FastJSONLoader
from line_compiler import LineBasedCompiler
from execution_engine import ExecutionEngine

# Инициализация компонентов
loader = FastJSONLoader()
compiler = LineBasedCompiler()
engine = ExecutionEngine()

# Загрузка и выполнение программы
json_data = loader.load_encrypted("programs/program.enc.json", device_key)
code_blocks = loader.extract_code_lines(json_data)
executable = compiler.build_executable(code_blocks)

# Выполнение установки и цикла
engine.execute_setup(executable['setup'])
engine.execute_loop(executable['loop_logic'], max_iterations=1000)
```

## Формат программ JSON

```json
{
  "metadata": {
    "version": "1.0",
    "signature": "ed25519_signature_here",
    "timestamp": "2023-12-01T10:00:00Z",
    "checksum": "sha256_checksum",
    "author": "Имя автора",
    "description": "Описание программы"
  },
  "config": {
    "runtime_limit_ms": 5000,
    "memory_limit_kb": 25,
    "permissions": ["gpio", "time"],
    "hot_reload_enabled": true
  },
  "imports": [
    "import machine",
    "import time"
  ],
  "functions": [
    "def blink_led(pin, duration):",
    "    pin.value(1)",
    "    time.sleep(duration)",
    "    pin.value(0)",
    "    time.sleep(duration)"
  ],
  "setup": [
    "led_pin = machine.Pin(2, machine.Pin.OUT)"
  ],
  "loop_logic": [
    "blink_led(led_pin, 0.5)",
    "time.sleep(1)"
  ]
}
```

## Меры безопасности

1. **Шифрование**: Все программные файлы зашифрованы с помощью AES-GCM
2. **Проверка подписи**: Цифровые подписи обеспечивают целостность
3. **Выполнение в песочнице**: Код запускается в ограниченной среде
4. **Контроль разрешений**: Ограниченный доступ к опасным функциям
5. **Ограничения ресурсов**: Принудительное ограничение времени и памяти
6. **Санитизация ввода**: Все входные данные проверяются и очищаются

## Управление памятью

Система включает MemoryOptimizer, который:
- Предварительно выделяет буферы для уменьшения фрагментации
- Отслеживает использование памяти
- Выполняет сборку мусора при необходимости
- Оптимизирует использование bytearray

## Тестирование

Система включает в себя комплексные модули тестирования:
- `performance_tests.py`: Измеряет производительность системы
- Встроенная проверка в каждом компоненте
- Проверки безопасности на протяжении всего процесса

## Ограничения

- Ограниченная стандартная библиотека MicroPython влияет на некоторые криптографические операции
- Ограничения памяти на ESP32 ограничивают сложность программ
- Нет функций реального времени для жестких гарантий по времени
